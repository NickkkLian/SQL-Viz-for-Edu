    About Query Mirror
    About this tool
    Four small synthetic datasets (hospital, e-commerce, movies, university) live inside engine.js; SQLite runs in your browser through sql.js 1.10.2 (vendored in vendor/). Every checkbox, filter, grouping and sort you set is turned into one SELECT, shown in the mirror and executed. Practice mode hides the mirror and grades the SQL you write against the same result. No build, no server, no account, nothing uploaded.
    Not verified here
    The engine and displayed SQL use SQLite syntax, including CAST(… AS TEXT) and LIMIT; queries are not verified against Oracle. The generator covers a teaching subset (inner and left joins along fixed keys, WHERE with AND/OR and LIKE, GROUP BY, HAVING, ORDER BY, DISTINCT, five aggregates); subqueries, self-joins and window functions are out of scope. Practice grading compares result sets, not SQL text. Exercise drafts and completion are saved only in this browser when storage is available; clearing site data removes them.
